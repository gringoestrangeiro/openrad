# OpenRad 2.1.5 — integração do plugin multiversão e do mod Fabric (não lançado)

Este conjunto de alterações foi baseado em `release/2.1.5` de `gringoestrangeiro`, **não** em `main` 2.1.0. Mantém a otimização de RAM/CPU e os testes acrescentados pelo mantenedor na 2.1.5.

## Plugin Paper

O plugin conserva todos os arquivos Java de produção e os testes da base 2.1.5, inclusive correções de 2.1.0. A ampliação de compatibilidade altera apenas a seleção da API `openradPaperApi`, o alvo do compilador Java e `api-version` mínimo declarado (`1.20.6`).

| Linha Paper | Build alvo | Java |
| --- | --- | --- |
| 1.21.x (1.21 a 1.21.11) | `1.20.6-R0.1-SNAPSHOT` | 21 |
| 26.1.1 | `26.1.1.build.+` | 25 |
| 26.1.2 | `26.1.2.build.+` | 25 |
| 26.2 | `26.2.build.+` | 25 |
| 26.3 | `26.3.build.+` | 25 |

Cada alvo moderno exige artefato e teste separado. **Paper 26.1 sem patch não está garantido** por faltar evidência de API publicável. Compilar uma API antiga não certifica gameplay em todas as versões mais novas. Os JARs são gerados somente se `test` e `verifyJar` passarem (`clients/plugin/scripts/build-paper-targets.ps1`).

## Mod Fabric

O código-fonte está em `clients/mod/`, com núcleo independente em `core/`, versões 1.21.x em `fabric/` e 26.x em `modern/`. As classes de protocolo compartilhadas foram sincronizadas com a 2.1.5 oficial, para preservar as correções de peer presence e as novas otimizações de CPU/RAM em criptografia, TCP, checksums e transporte. Os arquivos restantes do mod, inclusive telas, comandos, mixins e testes, vêm do protótipo de desenvolvimento existente.

Cada versão de Minecraft recebe um JAR específico. O arquivo `clients/mod/docs/BUILD-STATUS-1.21-26.3.json` é histórico **anterior à integração** e não comprova builds 2.1.5; os testes de CI serão a referência para os novos artefatos.

## Limites antes da liberação

Não criar tag, release ou instalar automaticamente o mod no Minecraft real. Os alvos de CI comprovam build e testes de código quando aprovados, não o percurso completo de login e gameplay nem compatibilidade em todos os hosts. Preservar identidades e configurações do usuário. A PR deve ser mesclada pelos mantenedores em `release/2.1.5` após revisão e validação, **sem publicar ainda**.
