## Minecraft Fabric client mod — `clients/mod/` (new)

Imported in pull request #14 (179 files). Review fixes before merging are in commit
`ecdf9b1`.

| Path | Contents |
| --- | --- |
| `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `gradlew*`, `gradle/wrapper/*`, `.gitignore`, `LICENSE` | Gradle build for 1.21.x (Java 21) with a pinned wrapper; MIT license. |
| `core/**` | Platform-independent client runtime: `ClientVpnRuntime`, `ClientPeerService`, `OutboundTcpStack` (virtual TCP), `LanServerRegistry`, `MinecraftCatalogQuery`, `PeerAuthorization`, `ClientConfig`, and byte-identical copies of the plugin's protocol classes under `openradplugin/`; JUnit suites and the shared cryptographic fixtures. |
| `fabric/**` | Fabric adapter for 1.21–1.21.11: loopback bridge, mixins for `Connection`, the legacy status ping and the Multiplayer screen, OpenRad menu screens, 14 locale files, tests. |
| `modern/**` | Fabric adapter for 26.1–26.3 (Java 25, Gradle 9.7.1 wrapper with pinned checksum). |
| `tools/*.py`, `build-*.ps1` | Per-version JAR verification and multi-target builds. |
| `README*.md`, `docs/**` | Guides, architecture, compatibility history and test notes. |

Review fixes: peer channels survive presence, rename and network-membership updates;
closed status pings no longer hold connection slots; joining a server skips peer backoff;
virtual TCP `flush()` no longer waits for acknowledgements; at most 8 LAN entries per peer;
first registration cannot be interrupted by Disconnect/Save; the legacy server-list ping
cannot crash the game; `26.x` addresses use the normal path while OpenRad is disconnected;
unknown language groups no longer crash the picker; screen text has an alpha channel
(visible on 1.21.6+ and 26.x); missing translations show English; an invalid configuration
file is kept for repair.
