# OpenRad 2.4.0 — detailed changes

This document describes the 2.4.0 integration and qualification boundaries.

## Contributors' work preserved

- Linux terminal/SSH and TTY authorization: the existing `2.4.0-dev` branch retains the terminal `sudo`/TAP descriptor handoff implementation, documentation, and tests.
- PR #23: Minecraft Paper/Fabric transport, identity lifecycle, configuration, security, and UI hardening with extensive regression coverage.
- v2.3.3: Android VPN protection refusal handling, including tests, is carried forward.
- PR #26: Simplified Chinese Android strings, with language-menu integration and localization validation.
- Issue #25: Android direct TCP and IPv6 preparation, with manual interoperability checks still pending.

## Compatibility and artifacts

The intended release uses version 2.4.0 across Rust desktop/CLI, Python, Android (Android package versionCode 10), Paper and Fabric, with a 2.4.0 versioned Go build. The coordinator wire format, cryptographic identity and user credentials are not intentionally changed.

Release installers, signed Android APKs, JARs, hashes and package inventories must be generated and verified from the finalized reviewed release commit.

## Remaining manual qualification

- Real Linux TAP authorization/SSH cancellation test.
- Real Android-to-official-Radmin direct TCP/IPv6 and relay fallback testing.
- CI version compatibility matrix at the final commit and native Windows packaging verification.
- Verify clean Android installation with the new pinned certificate; no signing secrets in Git. In-place upgrades from older signatures are not supported.

Unsigned and debug artifacts must never be distributed as production APKs.
