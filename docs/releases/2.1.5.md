# OpenRad 2.1.5 — stealth block, Minecraft mod, multiversion plugin and lower RAM

OpenRad 2.1.5 adds **stealth block** to the desktop, CLI and Android clients, a Minecraft
**Fabric client mod** (alpha), Paper plugin builds for Minecraft 1.21.x and 26.x, and lower
CPU/RAM use in the Rust client and the plugin. Wire formats, identities and saved
preferences are unchanged; upgrading from 2.1.0 keeps existing profiles.

## What is new

- **Stealth block (desktop, CLI, Android).** Block a peer's VPN IP for incoming traffic,
  outgoing traffic, or both. The address behaves as if it did not exist: its packets are
  ignored and nothing is sent to it, including ARP and broadcasts. The peer channel stays
  authenticated and connected, so keepalives and RTT continue, and unblocking restores
  traffic at once without reconnecting. Use **Settings → Stealth block**, or
  `openrad block VPN_IP [--incoming|--outgoing]`, `openrad unblock VPN_IP` and
  `openrad blocked`. The list is saved per profile (up to 1024 addresses) and applied live.
  An outgoing block is compiled into the forwarding table and costs nothing per packet. An
  incoming block costs one flag check per received record; blocked frames are never parsed,
  validated or queued. See the [CLI guide](../cli.md#stealth-block) and the
  [desktop guide](../desktop.md).
- **Minecraft Fabric client mod (alpha, new).** `clients/mod/` puts a Minecraft Java client
  inside an OpenRad network without TAP/TUN, drivers or system routes. Servers at `26.x.x.x`
  are reached through an authenticated in-process virtual TCP stack, and LAN advertisements
  from authenticated peers appear in the Multiplayer list. There is one JAR per Minecraft
  version: 1.21–1.21.11 (Java 21) and 26.1–26.3 (Java 25). Install only the JAR that matches
  your game. The integration (pull request #14) was reviewed before merging; the fixes
  are listed in the [change inventory](2.1.5-changes.md#minecraft-fabric-client-mod--clientsmod-new).
- **Paper plugin for more Minecraft versions.** The plugin now ships one JAR per Paper
  line: 1.21.x (Java 21) and 26.1.1, 26.1.2, 26.2 and 26.3 (Java 25). The protocol code is
  the same in every JAR; only the Paper API and Java target differ. Unpatched Paper 26.1 is
  not supported.
- **Lower RAM and CPU.** On Linux the CLI service and desktop cap glibc allocator arenas at 4
  and return freed heap pages to the OS periodically; the translation catalog is no longer
  copied to the heap; release binaries use fat LTO (`openrad` 9.0 → 6.2 MB,
  `openrad-desktop` 32.1 → 22.7 MB). The plugin copies each frame far fewer times, reuses
  ciphers and buffers, and stops polling at 100 Hz while idle. Equivalence tests pin the old
  byte-for-byte encodings.

## Upgrade

Stop the old shared service with `openrad stop` and close the desktop before replacing
binaries, and keep CLI and desktop from this release together. On Windows, run the new
installer. The Android APK installs over 2.1.0. For the plugin, replace the old
`OpenRadPlugin*.jar` in `plugins/` with the one for your Paper version; existing
`plugins/OpenRadPlugin` data is kept. For the mod, put exactly one
`OpenRadClientMod-2.1.5-fabric-<version>.jar` in the Fabric profile's `mods/` folder.

## Validation

Run on Linux for the release source:

- `cargo fmt --all -- --check`, `cargo test --workspace --locked` (347 passed, 8 ignored),
  Linux and `x86_64-pc-windows-gnu` Clippy with warnings denied, and
  `cargo test --workspace --target x86_64-pc-windows-gnu --no-run --locked` pass.
- `python3 scripts/check-sync.py` passes, including the new check that the mod's plugin
  classes and fixtures are byte-identical.
- Android `:app:testDebugUnitTest` passes (137 tests). The release APK is signed with the
  2.0.1 certificate (APK Signature Scheme v2) and reports `versionCode` 6, `versionName` 2.1.5.
- Python `run_tests.py` passes (15 tests, both passes).
- Plugin `./gradlew clean check` passes for each of the five Paper targets: 150 JUnit tests
  and `verifyJar` (116 classes at the target's Java bytecode level, metadata and license).
- Fabric mod: the shared core (93 JUnit tests) and the 1.21.x adapter (21 tests) pass for
  each 1.21.x target. All 17 JARs were built and checked by `tools/verify-version-jar.py`
  (exact Minecraft version, mod version, Java 21/25 bytecode, every mixin class present).

Linux binaries were built from the release commit in the established Debian 12 /
Rust 1.95 builder, with every tracked file verified against the source archive given to
it. Windows binaries were cross-built with MinGW-w64; the installer payload was verified
against the built files, and both executables report 2.1.5 under Wine.

Not measured: on-device Android behavior, native Windows TAP/UAC and installer cycles, the
plugin and mod with real players through the official Radmin VPN client (login, world
entry, multiple players), and starting each Minecraft/Paper version with the built JARs.
A successful build of a Minecraft target shows that it compiles, its mixins resolve and its
metadata is correct, not that it plays. Windows remains experimental.
