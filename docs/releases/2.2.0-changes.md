## Validacao

A candidata 2.2.0 usa workflows de Rust Linux, Windows nativo, Android, Python, sincronizacao, matriz Minecraft Fabric/Paper, smoke de cliente real 1.21.1 em Xvfb e empacotamento Linux/Windows. Os resultados so podem ser considerados aprovados apos cada GitHub Action terminar com sucesso. Ainda nao ha homologacao de VPN/Radmin ao vivo, instalacao TAP com UAC ou assinatura Android de producao. Veja [notas](2.2.0.md).
