# OpenRad 2.4.0

OpenRad 2.4.0 consolidates networking and stability improvements across the clients and self-hosted server. Paper and Fabric graduate from alpha to beta.

## Android signing change - clean installation required

The original Android signing key was lost. Starting with 2.4.0, OpenRad uses a new production signing key. Android will reject an in-place upgrade from 2.3.3 or earlier. Preserve any important app data before uninstalling; uninstalling can remove identity, favorites and settings. Install the new signed APK afterward. The application ID remains `com.openrad.mobile`, versionCode 10.

## Changes

- Rust Linux CLI: interactive terminal sudo for TAP setup in SSH/TTY, with descriptor handoff and validation; configurable interface names.
- Windows: reduced idle TCP/UDP polling and hidden PowerShell helpers during desktop startup. Windows remains experimental.
- Android: retains the v2.3.3 protect refusal handling, improves direct TCP rendezvous for both roles and numeric IPv6 candidates, and adds Simplified Chinese with an in-app language option.
- Paper/Fabric: transport, security, lifecycle and configuration hardening, plus regression tests and version-specific Minecraft compatibility builds.
- Python and self-hosted Go server: aligned 2.4.0 release metadata.
- Packaging: versioned Linux, Windows, Android, server and Minecraft packages with SHA-256 checksums.

## Validation and limitations

The integration candidate passed Rust, Go, Android, Python, sync, tooling and Minecraft compatibility CI. The runtime qualification passed local socket protocol tests and Android 14 emulator startup/VPN service; those are not tests against the official Radmin service. Real Android-device direct TCP/IPv6 and relay interoperability, native Windows TAP installation, and Linux SSH/TTY authorization remain manual qualification tasks. Minecraft beta does not imply full live gameplay coverage for every version.
