# OpenRad 1.0.0 — Complete change inventory

The comparison baseline is remote `origin/main` at
[`8d793b44`](https://github.com/gringoestrangeiro/openrad/commit/8d793b44a380c4d60aca43dd56fda6e4b5d77065)
(tag `v0.9.5`), fetched on 2026-10-01. There were no unpublished local commits.
The original workspace contained **35 modified tracked files and four new Rust
files**. This release commits those changes and the version/documentation/packaging
work required to publish 1.0.0: **53 files in total**, each accounted for below.
Ignored profiles, credentials, operational reports, build caches, and release
archives are excluded from Git; the audited distributions are release assets.

The [changelog](../../CHANGELOG.md#100--2026-10-01) explains all resulting behavior
and restores the full published version history. The [release notes](1.0.0.md)
record upgrade guidance, build/test evidence, and platform limits. Performance
changes preserve existing protocol/crypto/MTU/admission contracts and make no new
whole-process memory or throughput claim.
