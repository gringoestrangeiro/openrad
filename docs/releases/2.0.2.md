# OpenRad 2.0.2 (proposed, not released)

This document is a maintainer draft. No 2.0.2 installer or APK is published by this branch.
The wire format is unchanged.

Proposed fixes: Windows service startup without inherited pipes, a shared IPv4/IPv6
connect deadline, atomic settings and network-preference persistence, a Settings
uninstall flow that preserves identity and profiles, and Radmin Recovery without a
blocked diagnostic pipe.

Direct-path and incoming-offer stability from the local diagnostic analysis: relay no
longer preempts a working direct path, UDP rendezvous accepts learned ports on an
authenticated candidate's address, UES mapping requests are resent and tolerate a
lone reply, incoming offers request their own relay ticket, and abandoned offers are
released early. The Android engine carries the same changes.

Validation: the Linux workspace tests, Rust formatting, Linux and Windows-target
Clippy, and `scripts/check-sync.py` pass. Android unit tests were reported by the
contributor. Live TAP/VPN between two peers, UAC/driver installer cycles, elevated
Radmin IPC on Windows, and real-NAT behavior remain pending. Three Linux dependency
maintenance advisories remain: zvariant, zvariant_derive, zbus_names.

Keep the version as pre-release until release validation is complete.
