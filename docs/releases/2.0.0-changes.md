# OpenRad 2.0.0 — Complete change inventory

Baseline: freshly fetched `origin/main`, commit `d2f68d9` (v1.5.0).

This is a short inventory. The substance of this release is commit
`ca487c7` ("feat: monorepo with android + python clients,
installer/ANR/udp fixes, normalized logo"), which imports
`clients/android/` and `clients/python/`, hardens the Windows installer
and UDP parsers, normalizes branding under `assets/logo.svg`, and adds
the `rust`/`android`/`python`/`sync-check` CI workflows with
`scripts/check-sync.py`. See that commit for the per-file account; the
files below are this version bump itself.
