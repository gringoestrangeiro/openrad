# OpenRad 2.1.0 (prepared, not yet published)

This document describes the 2.1.0 source state. No 2.1.0 GitHub release, installer
or APK has been published from it yet. Wire formats, identities and saved
preferences are unchanged; upgrading from 2.0.1 keeps existing profiles.

## What is new

- **Minecraft Paper plugin (alpha).** `clients/plugin/` builds `OpenRadPlugin.jar`
  (Java 21, Paper 1.21.x). It is an in-process OpenRad client with a virtual TCP stack
  that forwards Radmin VPN players to the local Minecraft server on loopback; the host
  needs no VPN client, TAP/TUN driver or native code. Setup takes two console commands:
  `orb join "Network" password` and `orb status`, which prints the address players use.
  See the [root README](../../README.md#minecraft-server-plugin-paper), the
  [plugin guide](../../clients/plugin/README.md) and the
  [plugin 2.1.0 notes](../../clients/plugin/docs/changes-2.1.0.md) for the review fixes.
- **Membership presence (PR #10).** A member announced by the authenticated service with a
  coordinator is treated as online unless its state is explicitly offline; partial updates
  keep the known coordinator and presence. Rust and Android received this in PR #10; the
  Python client and the Paper plugin now match it.
- **2.0.2 maintenance work.** Direct-path and incoming-offer stability, Windows service
  startup, atomic settings persistence, the Settings uninstall flow and Radmin Recovery
  fixes, as described in the [2.0.2 notes](2.0.2.md) and
  [2.0.2 inventory](2.0.2-changes.md). 2.0.2 was never published separately.

## Validation

- `cargo fmt --all -- --check`, `cargo test --workspace --locked` (341 passed, 8 ignored), Linux and
  `x86_64-pc-windows-gnu` Clippy with warnings denied, and
  `cargo test --workspace --target x86_64-pc-windows-gnu --no-run --locked` pass.
- `python3 scripts/check-sync.py` passes.
- Android `:app:testDebugUnitTest` passes (134 tests).
- Python `run_tests.py` (both passes) passes, including the new membership test.
- Plugin `./gradlew clean check` (JDK 21) passes: 141 JUnit tests and `verifyJar`.

Not measured: the plugin with real players through the official Radmin VPN client
(login, world entry, multiple players), live service behavior of the new presence rule,
native Windows TAP/UAC and installer cycles, and on-device Android behavior. Windows
remains experimental. Three Linux dependency maintenance advisories noted for 2.0.2
(zvariant, zvariant_derive, zbus_names) are unchanged.
